System Architecture

Proposed Design Strategy

The proposed solution shifts from reactive to proactive security by establishing a multi-layered defense pipeline. It integrates high-fidelity IoT sensing, hybrid AI inference, and a custom lightweight consensus mechanism.

📊 Architecture Visualization

1. Data Collection Layer

Continuous acquisition of high-resolution telemetry (V, I, f, Load) via Phasor Measurement Units (PMUs) and Smart Meters, providing the raw signal required for millisecond-level visibility.

2. Preprocessing & Security Layer

Data is normalized for neural network ingestion. Simultaneously, SHA-256 Hashing creates an immutable fingerprint of the input, ensuring that the "truth" at the sensor remains the "truth" at the model.

3. Feature Engineering

The system intelligently maps Spatial Relationships between nodes and Temporal Dynamics over time, allowing the detection of complex, multi-stage grid attacks.

4. Hybrid AI Inference (CNN-LSTM)

Our core innovation: a dual-stream model where CNNs identify location-based faults and LSTMs identify time-based anomalies. Their fusion ensures maximum sensitivity to even the quietest adversarial signals.

5. Prediction & Decision Module

The model outputs a binary classification. Using soft-max probability, it determines if the current grid state is Normal (0) or represents a Fault (1) with high confidence levels.

6. Blockchain Decision System

Detected faults enter the Proof of Monitoring (PoM) consensus. This decentralized layer ensures that fault logs are tamper-proof and verifiable by all authorized grid participants.

7. Output & Automated Control

The validated decision triggers immediate Node Isolation and real-time dashboard alerts, enabling grid self-healing and an immutable audit trail for forensic review.
