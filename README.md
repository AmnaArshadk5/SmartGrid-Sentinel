# ⚡ Smart Grid Security using AI & Blockchain

## 📌 Project Overview
This project focuses on enhancing **smart grid security and reliability** using a hybrid approach of **Artificial Intelligence (AI)** and **Blockchain technology**. It aims to detect faults, anomalies, and cyber-attacks such as false data injection and electricity theft while ensuring secure and transparent energy data management.

---

## 🎯 Objectives
- Detect faults in smart grid systems using AI models  
- Identify anomalies such as electricity theft and data tampering  
- Improve security using blockchain-based data integrity  
- Enable real-time monitoring and intelligent decision-making  
- Combine AI + Blockchain for a hybrid smart grid framework  

---

## 🧠 Key Technologies Used
- Machine Learning / Deep Learning (CNN, LSTM, Autoencoders)
- Blockchain (for secure logging and transparency)
- Data Analytics
- Python (core implementation)
- Simulation-based datasets / public datasets (e.g., smart grid datasets)

---

## 📊 Features
- Fault detection in power grid systems  
- Electricity theft detection  
- Cyber-attack detection (FDI, replay attacks)  
- Secure data logging using blockchain  
- AI-based predictive analysis
